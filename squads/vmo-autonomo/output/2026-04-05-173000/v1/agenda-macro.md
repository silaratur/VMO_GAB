## Estrutura das Fases KPMG

### Fase AS-IS (S1 + S2): Compreensão do Estado Atual
- **Objetivo:** Documentar processos atuais, dores do ERP vigente (SAP ECC 6.0), requisitos por área
- **Metodologia:** Workshops presenciais por área funcional (Manutenção, Suprimentos, RH/DP, Finanças, Fiscal)
- **Cobertura:** 3 entidades × 5 temas = 15 sessões + 2 sessões (S2, 14/04 combinadas)
- **Entregável KPMG:** AS-IS por área validado pelas equipes

### Fase Benchmarking / Sandbox (S3 + S4): Avaliação das Plataformas
- **Objetivo:** Demonstrações dos 3 candidatos (SAP S/4HANA Rise, Oracle ERP Cloud, TOTVS Protheus)
- **Participação:** DTI Holding lidera; áreas validam aderência funcional
- **Score Model:** Pilares preenchidos durante esta fase (Produto 20%, Tecnologia 20%, Operações 10%)
- **Entregável KPMG:** Matrizes de aderência completas para os 3 fornecedores

### Fase Revisões + Entrega (S4 final + S5): Consolidação
- **Objetivo:** Score Final calculado, Relatório redigido, Apresentação preparada
- **Score Model:** Pilares Estratégico 30%, Cliente 10%, Financeiro 10% concluídos
- **Entregável KPMG:** Relatório Final + Apresentação Executiva (08/05/2026)
