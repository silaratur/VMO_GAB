Objetivo do Projeto

Desenvolver e entregar em produção uma plataforma web interna de gestão de ideias de inovação para o Grupo Águia Branca, com capacidade para atender 10.000+ colaboradores da holding e todas as divisões, contemplando os 6 módulos funcionais definidos no escopo com 13 requisitos funcionais Must Have, até 30 de novembro de 2026 (kick-off 01/08/2026), com investimento máximo de R$ 90.000,00, eliminando custo recorrente de R$ 80.000–90.000/ano com plataforma terceirizada e atingindo payback no primeiro ano de operação.

Justificativa de Negócio

💸 Problema Atual

Plataforma terceirizada custa R$ 80–90K/ano com modelo de licenciamento restritivo que impede a expansão para todos os colaboradores do Grupo (holding + VixPar + VAB + divisões de comércio).

Dependência de fornecedor externo impede customizações alinhadas ao processo interno de inovação do Grupo.

✅ Solução Proposta

Plataforma proprietária com as mesmas funcionalidades + melhorias, escalável para todos os colaboradores sem custo adicional por usuário. Stack recomendada por benchmark: Django/Node.js + React (4–8 meses típico).

Payback: 1º ano — Investimento único de R$ 90K elimina custo recorrente equivalente. ROI imediato.

Escopo do Projeto

✅ Dentro do Escopo

  • Portal web responsivo de cadastro de ideias (problema, ganhos, benefícios)
  • Módulo de campanhas e desafios lançados pelo time de inovação
  • Fluxo de aprovação pelo gestor da área do proponente
  • Mini gestão de projetos para implementação de ideias aprovadas
  • Módulo de mensuração e registro de ganhos obtidos
  • Gestão de perfis (colaborador, gestor, inovação, admin) — 10.000+ usuários
  • Autenticação segura com RBAC e domínios corporativos
  • Testes de aceitação (UAT) com o time de inovação
  • Treinamento de administradores e time de inovação
  • Documentação técnica e manual do usuário

🚫 Fora do Escopo

  • Integração com sistemas legados (ERP, RH, folha de pagamento)
  • Aplicativo mobile nativo (iOS/Android)
  • Migração de dados históricos da plataforma atual
  • Suporte pós-implantação além de 90 dias de garantia
  • Treinamento presencial de todos os colaboradores
  • Hospedagem e infraestrutura (responsabilidade TI do Grupo)
  • Integração com plataformas externas de crowdsourcing
  • Gamificação avançada, IA para triagem, mobile nativo
